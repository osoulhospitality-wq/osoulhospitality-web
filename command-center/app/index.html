النسخة التجريبية العامة
  • Dragon: متصل بسجل GitHub عام ومخصص للاختبار المنزوع الحساسية فقط.
  • الموردون والعقود: تخزين محلي على جهاز واحد؛ غير معتمد للإنتاج أو تعدد المستخدمين.
  • المستندات: تُحسب بصمة محلية ولا يُحفظ محتوى الملف.
  • القياسات: نسبة التسليم تحسب من وسوم الحالات النهائية في النطاق المختار. مدة المعالجة تستند إلى سجل التشغيل الخاص.
  • شرط الإنتاج: Supabase Auth + MFA + RLS + تخزين خاص + سجل تدقيق غير قابل للتلاعب.
