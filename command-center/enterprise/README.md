# Osoul Command Center — Enterprise Activation

هذه الحزمة تنقل v11 من التخزين المحلي إلى بيئة مؤسسية متعددة المستخدمين.

## القرار التقني

- Supabase: PostgreSQL + Auth + Storage + Row Level Security.
- n8n: التكاملات والتنبيهات ومسارات الاعتماد.
- Resend: البريد المعاملاتي.
- OCR: اختبار Google Document AI وAzure Document Intelligence على 30 مستندًا عربيًا/إنجليزيًا قبل التعاقد.

## ترتيب التفعيل

1. إنشاء مشروع Supabase داخل منطقة مناسبة لسياسة البيانات.
2. تشغيل `schema.sql` مرة واحدة من حساب المالك.
3. إنشاء حاوية خاصة `documents` ومنع الوصول العام.
4. إضافة المستخدمين وربطهم بجدول `profiles`.
5. إضافة مفاتيح الاتصال إلى بيئة الاستضافة؛ لا توضع الأسرار في Git.
6. اختبار أدوار Owner وApprover وAnalyst وViewer.
7. تفعيل n8n والتنبيهات بعد نجاح اختبار الصلاحيات.
8. تشغيل تجربة OCR ثم اعتماد المزود الأعلى دقة والأقل تكلفة.

## بوابة إطلاق الإنتاج

لا يُسمح برفع عقود حقيقية قبل نجاح MFA وRLS واختبار استعادة النسخ وسجل التدقيق وسياسة الاحتفاظ وفحص وصول مستخدم لا يملك صلاحية.
