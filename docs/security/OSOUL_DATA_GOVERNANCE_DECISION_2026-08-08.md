# قرار حوكمة البيانات — Osool Command Center

التاريخ: 8 أغسطس 2026  
النطاق: بوابة `osoulhospitality.com/command-center/enterprise/`، مشروع Supabase `fdkfxlvsluiqrgedokdm`، وربط HubSpot EU1.

## القرار التنفيذي

**Conditional Go للبيانات العامة وبيانات الشركات فقط، وHold for Evidence لأي بيانات شخصية أو سرية أو تعاقدية أو مالية.**

يُرفع التعليق فقط بعد اكتمال حساب المالك وTOTP، واعتماد تقييم نقل البيانات خارج المملكة، وتثبيت جدول الاحتفاظ، وإتمام اختبار نسخة احتياطية واستعادة.

## حدود البيانات المسموح بها مؤقتًا

مسموح:

- أسماء منشآت عامة وبياناتها التجارية المنشورة.
- نتائج QA غير الحساسة والموسومة بوضوح كبيانات اختبار.
- مراجع وروابط عامة لا تتضمن أشخاصًا طبيعيين.

ممنوع حتى رفع التعليق:

- أسماء الأفراد وأرقامهم وبريدهم غير العام.
- بيانات الهوية والموظفين والنزلاء والعملاء.
- العقود والفواتير والأسعار الخاصة والحسابات البنكية.
- أي بيانات صحية أو حيوية أو أمنية أو حساسة.
- مستندات عميل أو مورد غير منشورة.

## تقييم النقل خارج المملكة

التخزين في Seoul يُعد معالجة خارج المملكة عند إدخال بيانات شخصية من المملكة. قبل ذلك يجب توثيق:

1. الغرض والأساس النظامي لكل فئة بيانات.
2. طبيعة النقل، الأطراف، النطاق الجغرافي، والوصول عن بُعد.
3. الحد الأدنى اللازم من البيانات، والتشفير، والصلاحيات، والسجلات.
4. الضمان التعاقدي المناسب مع المعالج، بما في ذلك DPA وآلية نقل صالحة.
5. الأثر المحتمل واحتماله وخطة الإيقاف والإخطار عند فشل الضمانات.

## معيار رفع القرار إلى Go

لا يتحول القرار إلى **Go كامل** إلا إذا أُغلقت جميع البنود الستة بدليل قابل للتدقيق. وجود RLS أو شاشة MFA وحده لا يعوض غياب مستخدم موثّق أو قرار نقل أو اختبار استعادة.
