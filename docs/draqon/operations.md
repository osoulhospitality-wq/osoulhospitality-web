# دليل تشغيل دراقون واستعادة الخدمة

إصدار 26 نوفمبر 2026 | المالك المقترح: مدير التشغيل | حقل التطبيق: بيئة تجريبية خاصة بعد إثبات الهوية والحدود ووسيلة الإيقاف. تحتفظ أصول الضيافة بسلطة القرارات الجوهرية وبمسار بديل للبلاغات العاجلة.

## مسار المهمة ومتى تعد منجزة

| المرحلة | المسؤول | السجل المطلوب قبل الانتقال |
|---|---|---|
| 1. استقبال الطلب | خدمة الاستقبال | هوية المصدر، المنشأة، الوقت، معرف طلب مستقر ونوع القناة |
| 2. فهم الهدف | المنسق أو المناوب | وصف موجز ومعيار إنجاز يمكن التحقق منه، وسؤال توضيح فقط إذا منع الغموض التنفيذ |
| 3. استرجاع السياق | خدمة المعرفة | مراجع مفوضة وسارية تشمل المصدر والإصدار ونطاق المنشأة |
| 4. تصنيف المهمة | محرك التوجيه | نوع الإجراء والغرض، وحالة أولوية البلاغ العاجل عند انطباقها |
| 5. تقييم المخاطر | السياسة ومالك المجال | حساسية البيانات وعواقب الأثر الخارجي ومستوى الاستقلال |
| 6. تحديد الأولوية | مدير المناوبة | أثر السلامة وتعطل الخدمة وموعد SLA، مع سبب الترتيب |
| 7. إعداد خطة التنفيذ | قالب حتمي أو مخطط OpenAI | خطوات وأثر متوقع وحدود كلفة ودليل مطلوب وبصمة إصدار |
| 8. تحديد الوكلاء والأدوات | المنسق | عامل مسمى وأداة مسموحة ووجهة محددة لكل خطوة |
| 9. التحقق من الصلاحيات | محرك السياسة | تطابق المنشأة والهوية والنطاق والحالة والميزانية، وحالة الإيقاف |
| 10. المراجعة المستقلة | Claude أو مراجع بشري مفوض | نتيجة منظمة ومصدر لكل ملاحظة وفحوص مطلوبة، أو سبب تجاوز المراجعة وفق السياسة |
| 11. اعتماد القرار | صاحب التفويض | اعتماد محدد الصلاحية ومرتبط بالبصمة والمنشأة، أو إذن تلقائي مسبق وفق السياسة |
| 12. التنفيذ | العامل محدود الصلاحية | إعادة تحقق عند حدود الأثر ثم حجز ذري وتسجيل مفتاح التكرار ومعرف المحاولة |
| 13. التحقق من النتائج | مدقق مستقل عن العامل | قراءة من الوجهة أو إيصال مثبت ومطابق للطلب والموقع والأثر |
| 14. اختبار الجودة | صاحب الخدمة | نتيجة فحص القبول. للعمل الميداني يلزم دليل فني وإثبات الزيارة والعودة للخدمة حيث ينطبق |
| 15. تسجيل الأدلة | سجل الأثر | حفظ مرجع الدليل والطابع الزمني ومن جمعه وربطه بالمهمة |
| 16. تحديث الأنظمة | عامل التسوية | إصدار سجل الأمر أو الأصل أو CRM ومؤشر مزامنة بعد التحقق من الأثر |
| 17. إعداد التقرير | محلل الأداء | النتيجة مقابل المعيار والوقت والكلفة والانحراف وحالة الإجراء |
| 18. تسجيل الدروس | مالك التحسين | ملاحظة قابلة للتتبع أو إشارة موثقة إلى عدم وجود انحراف |
| 19. إغلاق المهمة | مالك التشغيل أو قاعدة إقفال مفوضة | استيفاء أدلة القبول وإقفال الذمة ومنع الإغلاق عند غياب الدليل |

## صلاحية التنفيذ والتوقف

| المستوى | مثال قابل للتشغيل | الحد الملزم في التصميم |
|---|---|---|
| L0 مراقبة | قراءة طابور منشأة مصرح بها | قراءة محدودة بالنطاق وتجميع آثار الوصول |
| L1 توصية | ترتيب أوامر العمل | إرفاق مصدر وتاريخ وقابلية الرجوع إلى القرار |
| L2 تحضير | كتابة مسودة دون إرسال | حفظ في مساحة المنشأة دون التزام خارجي |
| L3 تنفيذ بموافقة | إرسال التزام تعاقدي | بصمة دقيقة، اعتماد ساري، حد مالي ووجهة محددان |
| L4 تنفيذ روتيني | معالجة مهمة منخفضة المخاطر مدرجة مسبقاً | حصة وميزانية ومهلة ومفتاح تكرار وسجل تسوية |
| L5 تحسين محدود | تجربة تعديل قالب على عينة معزولة | حق اقتراح واختبار وتسليم تغيير للمراجعة، وموافقة منفصلة على السياسة أو النشر |

اختبار زر الإيقاف يبدأ بتحديد المنشأة والمفتاح والعملية الجارية. يوقف سجل الاختبار المحلي الحجز والتنفيذ اللاحق في نطاق المنشأة. الأثر الذي قطع حد الإرسال يدخل التسوية. هذا الاختبار لا يثبت إيقاف n8n المنشور أو جميع العمال. للإيقاف المؤسسي المطلوب قبل الإنتاج، يحدد مسؤول الحادث كل نقاط الإدخال والمستهلكين، ويوقف استقبال المهام الجديدة في القنوات المشمولة والصلاحيات عند الوسيط، ويتحقق من توقف الاستهلاك في كل نسخة ويحتفظ بالرسائل المعلقة. توثق هوية مشغّل الأمر والوقت والمعاملات الجارية، ثم يطابق مدقق مستقل الآثار الخارجية قبل إعادة التشغيل. يبقى مسار بلاغ الطوارئ البشري متاحاً وفق خطة الموقع، وتُختبر قدرته على استقبال البلاغ وتسليمه للمناوب في التمرين.

## مناوبة التشغيل والحوكمة التجارية

عند بدء المناوبة يطابق المشغل عمر أقدم مهمة مع SLA، ويتحقق من عدادات سجلات الموافقات والمهام غير المسوّاة وحالة آخر نسخة. خلال اليوم ترتب قائمة القرار حسب السلامة والتأخير والأثر المالي، ويُعيّن مسؤول وموعد متابعة لكل بند. عند التسليم يمرر المناوب قائمة المهام عالية المخاطر وأي بلاغ لم يؤكد استلامه؛ يوقع المناوب القادم إلكترونياً على تسلمها. أسبوعياً يراجع مالك الخدمة فشل التحقق وتدهور الجودة والتكلفة. شهرياً تطابق المالية فاتورة المورد مع الاستهلاك المقيد، وتراجع الإدارة أذونات الخدمة وميزانية الأخطاء وخطة التحسين.

للإنفاق فصلٌ بين طالب الشراء ومراجع العرض ومعتمد الالتزام ومطابق الفاتورة. يسجل الطلب مركز التكلفة والعملـة والضرائب المنطبقة وسقف الصرف ومدة صلاحية العرض ومصدر الاتفاق. تعتمد السلطة المالية المختصة أي سقف أو تغيير في معادلة التسعير. تُحجز التكلفة المحتملة قبل استدعاء النموذج، ثم تسوى بالاستعمال الحقيقي. دفعة أو طلب شراء أو رسالة سعر نهائية أو عقد يحتاج اعتماداً مستقلاً وفق المصفوفة المعتمدة. يعاد طلب الموافقة عند تغيير الوجهة أو المبلغ أو نطاق المنشأة أو انتهاء صلاحيتها. العائد المالي المتوقع فرضية موثقة حتى تحقق القراءة من النظام المالي الفعلي.

## القياس ومؤشرات الاتفاق

يعرف مالك المنتج «المهمة الناجحة» بأنها طلب فريد اكتمـل مع دليل قبول. تفصل الطلبات التجريبية والمكررة ويحتفظ بعداد مستقل لكل استبعاد وسببه. يحتسب جمع نفس الطلب بعد إعادة المحاولة مرة واحدة في مقام النجاح، بينما تدخل كلفة كل المحاولات في البسط المالي. يفصل العرض بين الاستقبال الأولي وزمن إغلاق العمل الميداني.

| المؤشر | طريقة القياس والمصدر المقترح | الهدف الأولي وشرط تفسيره |
|---|---|---|
| توافر الخدمة الحرجة | طلبات مسبار تتبع مساراً صالحاً لكل قناة وموقع ÷ جميع عينات المسبار المجدولة. تعرض الفجوات منفصلة | 99.9% شهرياً. يحدد العقد نافذة الصيانة قبل القياس |
| نجاح المسارات الحرجة | عدد المهام المؤهلة المتحققة ÷ الواردة المؤهلة ضمن فوج مكتمل المدة | ≥99.5%، مع عرض الفوج المفتوح منفصلاً |
| الاستجابة الأولية | من إرسال العميل إلى استلام معرف طلب محفوظ. P95 من سجلات العميل والخدمة المتزامنة | ≤3 ثوان للطلبات البسيطة حيثما أمكن؛ يقاس على الجوال وشبكة ممثلة |
| اختبارات الوظائف الحرجة | الوظائف الحرجة التي اجتازت اختباراً ذا دليل ÷ قائمة الوظائف الحرجة المعتمدة | 100% قبل الإصدار، لكل إصدار |
| تسجيل الحسّاس والتحقق من إذنه | عدد الآثار ذات سجل كامل، وعدد الآثار ذات تصريح سابق، كل منهما ÷ آثار الوجهات المستقلة | 100% لكل نسبة. يراجع الأمن أي اختلاف فوراً |
| مخاطر التسريب أو التكرار وجاهزية الإصدار | عدد تسريبات بيانات الاختبارات، أذونات مفقودة، معاملات حساسة مكررة، وملاحظات حرجة مفتوحة | صفر لكل عداد قبل النشر، مع تثبيت حدود الاختبار |
| قابلية تتبع القرار | عدد القرارات الجوهرية ذات مصدر واعتماد وإيصال نتيجة ÷ جميع القرارات الجوهرية | 100%، يراجع مدقق الأدلة عينة ويبلغ نقص التغطية |
| الكلفة والجودة | مجموع تكلفة النموذج والتشغيل والبشر ÷ المهام المتحققة، ونجاح المعيار الأعمى، ومعدل تدخل البشر | لا يُثبت سقف مالي قبل دورة أساس وعقد. يسجل زمن الإنجاز ومعدل الخطأ لكل فئة |

تجمّع لوحة المؤسس القرارات المستحقة، المنفذ مع مصدره، المتأخر مع سببه ومالكه، جودة التنفيذ وأثره على الأصل أو العقد، والمخاطر والفرص المقبلة. تعرض كل بطاقة آخر مزامنة ونطاق المنشآت والمقام، وتعرض «بيانات غير كافية» إذا غاب مصدر القياس. ## تصميم القياس

يقيس فريق التشغيل زمن الاستقبال من جهاز العميل حتى الإقرار المستمر، وزمن معالجة العامل من بدء المحاولة حتى التحقق من الأثر، وزمن إغلاق العمل الميداني من فتح البلاغ حتى اعتماد العودة للخدمة. يثبت تقرير كل تجربة إصدار المصدر والنموذج، وطبيعة البيانات، وعدد الطلبات المؤهلة، والاستبعادات وسببها، ونمط التزامن. تكرر الاختبارات على نفس توزيع المدخلات عند مقارنة الإصدارات. تحفظ الفواتير وسجلات المواقع في نطاق صلاحياتها.

## الحوادث والتعافي وإعادة التشغيل

1. **فتح الحادث.** يسجل المناوب وقت الكشف والقناة والمنشآت المتأثرة ومعرفات الارتباط وأولوية السلامة. يحول الخطر الآني للمناوب الميداني وفق خطة المنشأة المعتمدة، ويمنع انتظار رد نموذج.
2. **الاحتواء.** يوقف عامل النطاق المتأثر، ويضبط حالة التنفيذ عند التخزين. عند فقد قاعدة السياسة يمنع أي أثر خارجي يحتاج تصريحاً ويستخدم سجل بلاغات بديل. عند توقف AI تحفظ المسودة ويكلف مراجع بشري بالحالات المستعجلة. عند عطل n8n تحفظ الطلبات المعتمدة في قناة تشغيل بديلة مسجلة.
3. **التسوية.** تفرق المناوبة بين فشل معروف قبل الأثر وأثر مجهول بعد الإرسال. يعاد الأول بمهلة ومحاولات متباعدة ومحدودة؛ يرسل ما استنفدها لقائمة المعالجة اليدوية. يقرأ المختص الوجهة بمفتاح الارتباط للثاني، ويثبت الإنفاق قبل أي إعادة. عند غياب تأكيد المزود يبقى معلّقاً مع مالك وموعد متابعة.
4. **الاستعادة.** يحجز مسؤول البنية بيئة منفصلة، ويطابق بصمة النسخة، ويستعيد ملفات التنفيذ وإصدارات مخططات البيانات وإعدادات n8n والسجلات. يعاد ربط هويات مرحلية بمساعدة أمين الأسرار، ويمنع توجيه رسائل الاختبار إلى العملاء. تتم مطابقة سجلات الالتزامات والمعاملات مع مصادرها.
5. **التحقق.** يرفع مراقب مستقل طلباً اصطناعياً، ثم يقرأ أثره ويعيد تسليمه للتحقق من منع الازدواج. يختبر المدير وصول المناوب وسلامة عزل المنشآت ووجود دليل الموافقة، ويتحقق من حالة الطابور والوصلات ووقت آخر كتابة سليمة.
6. **إعادة الخدمة.** يوقع مالك الخدمة وأمين الأمن حيث يلزم، وتفتح منشأة تجريبية محددة، ثم يتوسع النطاق عند ثبات مؤشرات الخطأ والتكلفة وعدم ظهور أثر مجهول. تسجل ساعة العودة وتفقد جميع البلاغات اليدوية قبل إغلاق الحادث.
7. **تراجع إصدار.** يحفظ الإصدار وإعداداته وخطة توافق البيانات قبل التغيير، ويوقف التوسع حال خطأ إذن أو خصوصية أو ازدواج أو تعذر التدقيق. يعاد ربط الإصدار السابق المتوافق، وتستعاد البيانات اختبارياً إن استلزم المخطط ذلك. يقيّم أثر المعاملات التي تمت أثناء الإصدار مع مالكها قبل إجراء تصحيحي. تسجل البصمات ونتيجة اختبار رجوع مستقل.

| الخدمة | RTO / RPO مقترحان | دليل القبول في تمرين مستقل |
|---|---|---|
| استقبال الأعطال العاجلة | ساعة / 15 دقيقة | بلاغ مؤرخ وصل وأُسند إلى المناوب، مع تسوية البلاغات خلال الانقطاع |
| دفتر التفويض والآثار | 4 ساعات / 15 دقيقة | مطابقة دفتر الموافقات مع الوجهة وإثبات عدم تكرار عينة أثر مالي |
| صياغة ومراجعة | 8 ساعات / 24 ساعة للمسودات | اكتمال مسودة مرجعية وحفظ مخرج مراجعة صالح |
| لوحة المالك | يوم عمل / 24 ساعة | يطابق رقم مع سجل المصدر ويظهر وقت اللقطة والفترة المفقودة |

يبدأ RTO من إعلان فقد الخدمة وينتهي بقبول معاملة ذات دليل. يقاس RPO من آخر كتابة يفترض حفظها إلى آخر كتابة سليمة مستعادة. تعتمد الإدارة هذه الأهداف بعد تحديد تكلفة الحفظ والتوافر ونسخ الأدلة. ## مراحل التسليم ونقاط القرار

| المرحلة | العمل | شرط الانتقال والمالك |
|---|---|---|
| 1. الاكتشاف | جرد المصدر والتكاملات والأذونات | يثبت مالك المنصة نطاقات البيئة وحقوق الحسابات ومصادر البيانات |
| 2. التصميم | حدود الخدمة والسياسة والمراجعة | يعتمد مالك المنتج تصنيف القرارات والموازنة |
| 3. المعالجة | تغيير معزول مع اختبارات قابلة للتكرار | يقبل المراجع المستقل التغيير والنسخة الاحتياطية |
| 4. المراجعة المستقلة | تجربة مدخلات اصطناعية معتمدة على حساب مرحلي | يتحقق مسؤول التكامل من المخرج المنظم والإنفاق ومقارنة الجودة |
| 5. التحقق | تجربة كاملة من استقبال إلى إيصال | يثبت مالك التشغيل زمن الاستجابة وإعادة التسليم والتعافي والتكلفة |
| 6. الإطلاق المقيد | تجربة منشأة ضمن حدود مفوضة | يوقع صاحب الصلاحية بعد نجاح الإيقاف والتراجع |
| 7. التحسين | مقارنة تقدم الإصدار بخط الأساس | يعتمد مالك الإصدار التغيير بعد تدقيق الأثر |

كل تغيير جوهري يربط مشكلة قابلة للقياس بفرضية إصلاح، وباختبار تراجع، ثم اقتراح تغيير في مساحة معزولة ومراجعة بشرية أو مستقلة مع تحقق موضوعي. يقارن التشغيل المراقب جودة الإجراء وكلفة المهمة والأخطاء بفترة أساس مماثلة. لا يمنح مسار التحسين تعديلاً ذاتياً لسياسة الصلاحية أو حدود الميزانية أو تبديلاً تلقائياً لشروط العقود.
