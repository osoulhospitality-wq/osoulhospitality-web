# التشغيل الداخلي والتحقق من الأدلة

يشغّل مسؤول مخوّل هذا البرنامج في بيئة محلية على Node.js 24. يعالج مساري عمل فعليين على بيانات يوردها المشغّل: حصر أوامر العمل المتأخرة عند وقت الرصد، وحساب انحراف الإنفاق بالهللة عن ميزانية الفترة نفسها. مهمات COO وCFO هنا حسابية حتمية. يحتاج الاتصال بأنظمة المصدر أو استدعاء نموذج أو استعمال عائد مالي منشور إلى مسارات منفصلة. يتولى CQO المقارنة بقيم متوقعة من مصدر مستقل. الوسوم الوظيفية في المحاكاة تُضبط بواسطة المشغّل المحلي، وتحتاج واجهة تشغيل متعددة المستخدمين إلى ربطها بهوية خارجية موثقة قبل الإتاحة.

## تشغيل تجربة قابلة للتكرار

من مجلد المستودع: `node --test automation/corporation/operations.test.mjs`. تنشئ الاختبارات دفاتر SQLite مؤقتة، وترصد نجاح وفشل المراجعة، وتحجب بيانات الشركة الأخرى، ثم تُغلق وتحذف سجلات الاختبار.

لتشغيل عينة قابلة للفحص، ينشئ الأمر التالي مصدرًا اصطناعيًا مؤقت الصلاحية وقيمًا متوقعة مستقلة. لا يكتب البرنامج في أي خدمة إنتاج.

```sh
workdir="$(mktemp -d)"
chmod 700 "$workdir"
node --input-type=module - "$workdir" <<'JS'
import { writeFileSync } from 'node:fs';
const dir=process.argv[2], now=new Date();
const source={
  kind:'sar_budget',reference:'fixture.ledger.v1',observedAt:now.toISOString(),
  expiresAt:new Date(+now+3600000).toISOString(),
  rows:[{id:'repairs',actualHalala:12000,budgetHalala:10000}]
};
writeFileSync(dir+'/input.json',JSON.stringify(source));
writeFileSync(dir+'/expected.json',JSON.stringify({currency:'SAR',lines:1,actualHalala:12000,budgetHalala:10000,varianceHalala:2000}));
JS
ops() { node automation/corporation/operations.mjs "$workdir/store.db" osoul "$@"; }
ops ingest monthly-budget "$workdir/input.json"
ops plan budget-review monthly-budget 1
ops execute budget-review CFO
ops review budget-review CQO "$workdir/expected.json"
ops close budget-review
ops report budget-review
```

## التشغيل والحوكمة

- يحدد المالك الشركة المصرح بها ومرجع الملف وفترة الرصد وتاريخ انتهاء صلاحيته. يُقبل لكل مسار نوع معرفة محدد وحقول محددة. لا تقبل الجداول أسماء عملاء أو عناوين بريد إضافية. استخدم حساب خدمة مقيدًا في التطبيق الفعلي.
- يرفض التخطيط مصدرًا قديمًا أو محجوبًا أو غير موجود. يربط كل تكليف بنسخة المصدر وبوكيل منفذ ومراجع. يبقى مصدر الوقت هو وقت الرصد، حتى لو شُغّل التقرير لاحقًا.
- يخزن الدفتر داخل معاملة واحدة نتيجة كل انتقال وبصمة دليله. يقيّد معرف المهمة داخل الشركة، ويُبقي المراجعة المرفوضة متاحة. صلاحية قراءة ملف الدفتر مسؤولية نظام التشغيل. لا يحتوي هذا التطبيق على واجهة شبكية أو طبقة هوية بشرية أو سجل غير قابل للتغيير على مستوى مدير الخادم.
- عند تعارض دليل المراجعة تُحجب المهمة. بعد فحص السبب ينشئ `ops correct OLD NEW SOURCE VERSION` مهمة تصحيح مرتبطة بالسابقة، ثم يُعاد التنفيذ والتحقق. لا يُعاد استخدام رقم مهمة لتغيير مصدرها.
- تعمل `ops pause` و`ops resume` على هذا الدفتر وهذه الشركة فقط. تبقى تقارير الأعمال السابقة قابلة للقراءة أثناء الإيقاف. لا يمتد الإيقاف إلى خدمات الإنتاج.
- كلفة الاستدلال في هذين المسارين صفر استدعاءات نموذج. وقت المشغّل وكلفة الجهاز والاستضافة خارج القياس.
