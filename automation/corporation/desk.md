# مركز القيادة وقاموس القياس

افتح النسخة الداخلية عبر خادم محلي مربوط بالجهاز. يتطلب تحميل وحدات المتصفح HTTP. نفّذ من جذر المستودع:

```sh
python3 -m http.server 8765 --bind 127.0.0.1 --directory automation/corporation
```

افتح `http://127.0.0.1:8765/desk.html`. اختر الإدارة، ثم وسّع المؤشر لعرض تعريفه ومعادلته ودوريته ومصدره والمسؤول عنه. اكتب معرف الشركة كما سجل في دفتر المهمة ثم حمّل ملف JSON الخاص بها. يتوفر اختيار العربية والإنجليزية. روابط بوابة المالك وسجل القرارات تفتح الدخول الرسمي إلى أصول وتتبع الصلاحيات القائمة.

لإظهار مهمة جرى تنفيذها في الدفتر المحلي، استخدم ملف قاعدة البيانات ومعرف الشركة والمهمة المُنشأة في `operations.md`. احفظ ملف التصدير خارج مجلد الخادم وبصلاحية خاصة:

```sh
umask 077
node automation/corporation/operations.mjs "$workdir/store.db" osoul report budget-review \
 | node automation/corporation/desk-export.mjs osoul > "$workdir/owner-snapshot.json"
```

يصدر المحول حالة المهمة وأحداثها عبر قراءة تقريرها. تبقى مؤشرات أداء الشركة فارغة إذ لا تمثل مهمة واحدة مجموع إنفاق الشركة. يوسم العرض بأنه دفتر محلي. يتحقق المحول من نطاق المهمة ومن إيصالي المراجعة والإغلاق قبل عرض حالتها كمكتملة. تحميل ملف يورده المستخدم يعرض ادعاءات المصدر، وتحتاج المراجعة المستقلة إلى الرجوع للسجل الأصلي. لا ينقل المركز الملف إلى خادم، ولا يحفظ محتوياته عند إغلاق الصفحة. غيّر الشركة أو اضغط مسح لإزالة اللقطة المعروضة. لا تضمّن معلومات شخصية أو أسرارًا في ملفات القياس.

## استيراد قياس أو قائمة

حقول الملف هي `version: 1`، و`origin` بقيمة `operational-export` أو `local-ledger` أو `synthetic`، و`tenant` و`from` و`to` و`asOf` و`metrics` و`items`. حقول الوقت تتطلب تاريخًا بصيغة ISO مع منطقة زمنية. لكل بند شركة مطابقة، و`sourceRef` (مرجع في المصدر المعتمد)، و`observedAt` (وقت قراءة الإثبات بعد انتهاء الفترة وقبل إصدار اللقطة). الفترات حسب تقويم الرياض. يمكن تحميل لقطة قديمة؛ وقتها ظاهر للمراجع.

- صف المؤشر يتضمن `id` من `kpis.mjs`، و`coverage` بقيمة `complete` أو `partial`، و`inputs` يحتوى الأرقام المجمعة من المصدر بأسماء الحقول المعروضة في المعادلة. عند غياب التغطية أو العامل أو المقام ينتج «غير متاح». الصفر المقاس يظل صفرًا. قيم النقد بالريال قبل ضريبة القيمة المضافة. توحّد نطاقات الإيراد والتكلفة وفترات الإسناد قبل التصدير. يسجل الهدف بمصدر قرار المالك في نظام الحوكمة قبل إضافته إلى قاموس الإصدار.
- صف المتابعة يتضمن `feed` (أحد الأقسام المذكورة في `desk-evidence.mjs`)، و`key` و`title` و`owner` و`status`. الحقل الاختياري `due` تاريخ استحقاق موثق، و`progress` نسبة إنجاز مشروع من المصدر. الفترة الخالية تعرض غياب البنود الموردة دون استنتاج وجود صفر من البنود في الإنتاج.
- واجهة العرض للقراءة. أوامر تشغيل الدفتر وإيقافه محصورة بمسؤول المضيف كما في `operations.md`. تعديل الصلاحيات أو اعتماد إنفاق أو إيقاف قناة نشر إنتاجية يستلزم مسارًا موثقًا لدى مقدم الخدمة وصلاحية مالك فعلية.
